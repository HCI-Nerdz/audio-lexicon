== About The Project

Professional audio apps expose filters and routing terms that mean little without history and audition.
*audio-lexicon* puts a searchable term tree on the left and, for each term:

* plain-language meaning
* historical / original usage
* visualization
* live parameter controls
* A/B audition on royalty-free music
* EqualizerAPO / OBS export snippets when mappable

Not a system-wide APO host and not an OBS upstream contribution.
Part of link:https://github.com/HCI-Nerdz[HCI Nerdz].

=== Architecture

[source]
----
catalog/            shared terminology + sample metadata (source of truth)
schemas/            JSON Schema for catalog validation
packages/core-ts/   parse, search, params, export, Web Audio recipes
adapters/web        Vite reference UI (GitHub Pages)
adapters/d-gtkd     D + GtkD
adapters/cpp-qt     C++ + Qt 6 (EqualizerAPO-aligned)
adapters/cpp-imgui  C++ + Dear ImGui
adapters/rust-iced  Rust + iced
adapters/rust-egui  Rust + egui
adapters/obs-dock   out-of-tree OBS Qt dock (do not upstream)
----

== Getting Started

=== Prerequisites

* link:https://nodejs.org/[Node.js] and link:https://pnpm.io/[pnpm]
* Optional: toolkit SDKs for native adapters (see each adapter README)

=== Web demo (local)

[source,shell]
----
pnpm install
pnpm prepare:audio
pnpm validate:catalog
pnpm dev
----

The Pages demo uses Vite `base` `/audio-lexicon/` under `hci-nerdz.github.io`.

=== Native adapters

See each adapter `README.adoc` for toolkit-specific build steps (GtkD, Qt 6, ImGui, iced, egui, OBS plugin template).

== Usage

Open the web demo, pick a term from the tree (or use `?term=` in the URL), read meaning and history, adjust controls, Play a curated sample, and copy EqualizerAPO / OBS export snippets when shown.

In-repo Diátaxis stubs live under `docs/` (explanation, how-to, reference). Org docs hub: link:https://hci-nerdz.github.io/docs/[hci-nerdz.github.io/docs].
