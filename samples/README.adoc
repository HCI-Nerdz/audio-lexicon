= Samples

== Curated (offline)

`samples/curated/tone-bed.wav` is generated by `pnpm generate:tone` and is released as **CC0-1.0** (public domain dedication) by HCI Nerdz.

== Online browser

The web UI “Download samples” pane lists curated metadata and opens Internet Archive searches for CC / public-domain audio.
`pnpm fetch:samples` optionally caches a few IA items under `samples/cache/` (gitignored via allow-list — not committed) and writes `manifest.json` with license URLs.

Never ship scraped tracks without license metadata in the catalog.
